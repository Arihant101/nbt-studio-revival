# 🎃 NBT Studio Revival

NBT Studio, the beloved Minecraft NBT editor, died. We dug it up and put it in your browser.
Built with [Kiro](https://kiro.dev) for Kiroween 2026 (Resurrection category).

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm test         # vitest
npm run build
```

## Layout
- `src/nbt/` parser, serializer, tag model
- `src/store/` Zustand store
- `.kiro/steering/` rules Kiro follows
- `.kiro/hooks/` typecheck + parser tests on save
- `.kiro/specs/` generated by Kiro from `SPEC_PROMPT.md`
